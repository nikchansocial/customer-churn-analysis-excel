# Customer Churn Analysis Dashboard (Excel)

## Overview

This project analyzes customer churn data from a fictitious telecom company to identify customer retention patterns, churn drivers, and business insights using Microsoft Excel.

The project focuses on KPI visualization, dashboard reporting, and business intelligence techniques to support data-driven decision-making.

This project was inspired by and professionally enhanced from the DataCamp case study:
"Case Study: Analyzing Customer Churn in Excel".

---

## Project Context

Customer churn is one of the most important business challenges for subscription-based companies because retaining existing customers is often more cost-effective than acquiring new ones.

This project explores customer behavior data to identify churn patterns and improve retention understanding through Excel-based analytics and dashboard visualization.

---

## Business Problem

Businesses lose revenue when customers discontinue their services. Understanding churn behavior helps organizations improve customer retention strategies and reduce acquisition costs.

The goal of this project is to analyze customer churn patterns and visualize actionable business insights using Excel dashboards.
